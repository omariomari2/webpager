# Immigration Assistant website

The public website for Immigration Assistant, an exploration of immigration information, status records, and employer research.
This repository contains the landing page. The [application source](https://github.com/omariomari2/immigrationassist) is separate.

## Stack

Express and EJS, with an optional static export.
The page retains Webflow assets and browser animations from its source template.

## Run locally

```sh
npm ci
npm start
```

Open the address printed by the server.
Run `npm test` to check the static export. Run `npm run build` to generate `docs/`.
See [static hosting](STATIC-HOSTING.md) for deployment steps.

## Status

A project website with beta application access described as coming soon.
External images, scripts, and widgets still require network access.
